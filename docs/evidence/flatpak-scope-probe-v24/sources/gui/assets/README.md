These unchanged GNOME Adwaita symbolic SVGs provide hicolor fallbacks for the application’s existing icon names. A valid selected desktop theme retains priority. Performance uses an alias for the upstream power-profile-performance icon. PROVENANCE.json records archive and source hashes; ADWAITA_NOTICE preserves upstream attribution and licensing.

Cargo compiles omen.gresource.xml using glib-compile-resources (GLib development tools). The binary embeds this resource. These SVG sources and notices are also included in the installed package. No runtime download or system theme change is needed.
